Coursework Summary

This coursework project was developed using BabylonJS, JavaScript, and HTML. The project consists of five separate elements, each demonstrating different areas of 3D game development and interactive web programming.

Each element focuses on different technical skills including:

* Mesh generation
* Lighting systems

* Keyboard controls
* Collision systems
* Animation
* Scene switching
* User interaction

The project was uploaded and hosted using GitHub Pages.

⸻

Project Aim

The aim of this project was to create an interactive BabylonJS application that demonstrates the use of multiple 3D scenes, object animation, user input, GUI systems, and scene management.

The project was designed to allow the player to switch between two different scenes using keyboard controls. Each scene contains different lighting, objects, colours, and animations to make them visually distinct.

The project also demonstrates understanding of:

* Scene creation
* Camera systems
* Lighting systems
* Mesh generation
* GUI implementation
* Animation systems
* Keyboard interaction
* Render loops
* Scene disposal and optimisation

⸻

Planning and Initial Ideas

Originally, I planned to create a more physics-based environment similar to a small interactive sandbox where the player could interact with objects and create collisions. I attempted to experiment with physics systems inside BabylonJS, however I experienced several issues with the setup and behaviour of the physics engine.

Because of these technical difficulties, I decided to redesign the project into a cleaner and more stable scene switching system. This allowed me to focus on improving interaction, animation, GUI systems, and overall stability.

Although the final version is simpler than the original concept, the completed project still demonstrates strong understanding of BabylonJS fundamentals and interactive scene management.

⸻

Overview

For Element 5, I created a multiple scene switching project using BabylonJS. The aim of this element was to demonstrate scene management, user interaction, GUI implementation, and animation inside a 3D environment. The user is able to switch between two different scenes using keyboard controls.

Scene A contains a rotating box with a green background, while Scene B contains a rotating and bouncing sphere with a blue background. GUI text was added to both scenes to help the user understand which scene is currently active and which keys can be used to switch scenes.

This element improved from the original version because motion and interaction were added to the scenes, making the project more creative and dynamic.

Description

Scene A is the first scene loaded when the project starts. The scene contains:

* A rotating box
* A ground mesh
* Lighting
* A controllable camera
* GUI text instructions

The box rotates continuously to make the scene more visually interesting. A GUI message is displayed to tell the user how to switch scenes.

Scene A Code Explanation

The first part of the code creates the scene and sets the background colour:

const scene = new BABYLON.Scene(engine);
scene.clearColor = new BABYLON.Color3(0.2, 0.5, 0.3);

This creates a new BabylonJS scene and changes the background colour to green.

⸻

Camera Setup

const camera = new BABYLON.ArcRotateCamera(
    "camA",
    Math.PI / 4,
    Math.PI / 3,
    10,
    BABYLON.Vector3.Zero(),
    scene
);
camera.attachControl(canvas, true);

An ArcRotateCamera was used so the user can move around the scene using the mouse.

⸻

Lighting

const light = new BABYLON.HemisphericLight(
    "lightA",
    new BABYLON.Vector3(0, 1, 0),
    scene
);

A hemispheric light was added to illuminate the scene evenly.

⸻

Ground and Box

const ground = BABYLON.MeshBuilder.CreateGround(
    "groundA",
    { width: 6, height: 6 },
    scene
);

This creates the ground mesh.

const box = BABYLON.MeshBuilder.CreateBox(
    "boxA",
    { size: 2 },
    scene
);
box.position.y = 1;

This creates the rotating box and moves it above the ground.

⸻

Rotation Animation

scene.registerBeforeRender(() => {
    box.rotation.y += 0.02;
});

This code runs before every frame is rendered. It rotates the box continuously on the Y axis.

⸻

GUI Text

const guiA = BABYLON.GUI.AdvancedDynamicTexture.CreateFullscreenUI("UIA");
const textA = new BABYLON.GUI.TextBlock();
textA.text = "SCENE A - Press 2 to switch";
textA.color = "white";
textA.fontSize = 32;
textA.top = "-40%";
guiA.addControl(textA);

Babylon GUI was used to display instructions on screen. The text tells the user how to switch to Scene B.

Scene B Code Explanation

Scene Setup

const scene = new BABYLON.Scene(engine);
scene.clearColor = new BABYLON.Color3(0.2, 0.3, 0.6);

This creates Scene B and changes the background colour to blue.

⸻

Directional Light

const light = new BABYLON.DirectionalLight(
    "lightB",
    new BABYLON.Vector3(-1, -2, -1),
    scene
);
light.position = new BABYLON.Vector3(10, 20, 10);

A directional light was used to create stronger shadows and improve the appearance of the sphere.

⸻

Sphere Creation

const sphere = BABYLON.MeshBuilder.CreateSphere(
    "sphereB",
    { diameter: 2 },
    scene
);
sphere.position.y = 1.4;

This creates the sphere and positions it above the ground.

⸻

Sphere Animation

scene.registerBeforeRender(() => {
    sphere.rotation.x += 0.04;
    sphere.rotation.y += 0.04;
    sphere.position.y = 1.4 + Math.sin(Date.now() * 0.005) * 0.5;
});

This animation makes the sphere rotate and bounce continuously.

The Math.sin() function was used to create smooth movement.

⸻

GUI Text

const guiB = BABYLON.GUI.AdvancedDynamicTexture.CreateFullscreenUI("UIB");
const textB = new BABYLON.GUI.TextBlock();
textB.text = "SCENE B - Press 1 to switch back";
textB.color = "yellow";
textB.fontSize = 32;
textB.top = "-40%";
guiB.addControl(textB);

This GUI text displays instructions for returning to Scene A.

⸻

Scene Switching System

Description

The scene switching system allows the user to move between Scene A and Scene B using the keyboard.

* Pressing 1 loads Scene A
* Pressing 2 loads Scene B

This system disposes of the old scene before loading the new one.

⸻

Switch Scene Function

const switchScene = (sceneCreator) => {
    if (currentScene) {
        currentScene.dispose();
    }
    currentScene = sceneCreator();
};

This function checks if a scene already exists. If it does, the scene is removed using dispose(). A new scene is then created.

⸻

Keyboard Controls

window.addEventListener("keydown", (event) => {
    if (event.key === "1") {
        switchScene(createSceneA);
    }
    if (event.key === "2") {
        switchScene(createSceneB);
    }
});

This event listener checks which key the user presses and switches to the correct scene.

⸻

Problems Encountered

During development, several problems occurred.

Scene B Freezing

Initially, Scene B froze when switching scenes. This happened because the Babylon GUI library was missing from index.html.

The issue was fixed by adding:

<script src="https://cdn.babylonjs.com/gui/babylon.gui.min.js"></script>

This allowed the GUI system to load correctly.

⸻

Sphere Clipping Through Ground

The sphere originally passed halfway through the floor while bouncing.

This was fixed by increasing the sphere height and adjusting the bounce calculation:

sphere.position.y = 1.4 + Math.sin(Date.now() * 0.005) * 0.5;
