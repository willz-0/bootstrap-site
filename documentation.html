Element 5 – Multiple Scene Switching

The purpose of Element 5 was to demonstrate scene management within Babylon.js. Two separate scenes were created that can be loaded and unloaded dynamically. This demonstrates how Babylon.js can manage multiple independent scenes within the same application.

Scene A

Scene A contains a rotating cube positioned above a ground plane. A hemispheric light was used to illuminate the scene and a green background colour was chosen to distinguish it from the second scene.

Scene B

Scene B contains a sphere positioned above a ground plane with a blue background. The sphere rotates and moves vertically using a sine function to create a floating animation effect. GUI text was added to provide instructions for switching back to Scene A.

Scene Switching

A switchScene() function was implemented to manage scene changes. The current scene is disposed before the selected scene is loaded, helping to prevent unnecessary memory usage and maintain performance.

Keyboard input was implemented using a keydown event listener. Pressing the "1" key loads Scene A, while pressing the "2" key loads Scene B.

Conclusion

Element 5 successfully demonstrates scene creation, scene disposal, animation and user interaction. The implementation provides a foundation for more advanced scene management systems that could be developed in future projects.
