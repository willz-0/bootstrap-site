Introduction

This coursework project was developed using Babylon.js to create interactive 3D environments inside a web browser.

  • HTML
  • JavaScript
  • Babylon.js

Element 1 – Basic Scene

Demonstrates Babylon.js fundamentals including cameras, lighting, materials, and basic 3D objects.

ArcRotateCamera and directional lighting were used to create shadows and scene control.

Element 2 – Environment

Demonstrates terrain creation, environmental assets, skyboxes, and scene decoration.

Height maps and SpriteManager were used to create a large outdoor environment.

Element 3 – Physics & Interaction

Demonstrates player movement, collisions, imported models, and physics systems.

Physics and collision systems allow the player to interact with the environment realistically.

Element 4 – GUI & Logic

Demonstrates GUI systems, jumping, movement logic, and health mechanics.

Babylon GUI was used to create a dynamic health bar system.

Element 5 – Scene Switching

Demonstrates switching between multiple Babylon.js scenes dynamically.

Keyboard input allows switching between Scene A and Scene B dynamically.
