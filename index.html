JavaScript Games Coursework

This website presents the development of a JavaScript game using Babylon.js. Each section demonstrates a different technical element of 3D game development.

Project Elements Overview

    • Element 1 – Basic Scene Setup: Demonstrates the creation of a Babylon.js scene including camera configuration, lighting setup, materials and animated 3D objects.
    • Element 2 – Environment Design: Demonstrates the development of a larger environment using terrain, textures, imported assets and scene decoration to create a more immersive world.
    • Element 3 – Player Interaction: Demonstrates character movement, keyboard controls, camera following, collision detection and interaction within a 3D environment.
    • Element 4 – Game Logic: Demonstrates gameplay systems including gravity, collision handling, obstacle interactions, health management and graphical user interface (GUI) elements.
    • Element 5 – Scene Management: Demonstrates dynamic scene switching, keyboard input handling, object animation and memory management through loading and unloading multiple Babylon.js scenes.
