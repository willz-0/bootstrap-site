JavaScript Games Coursework

This website presents the development of a JavaScript game using Babylon.js. Each section demonstrates a different technical element of 3D game development.

Element Documentation

  • Element 1 – Basic Scene: Using Babylon.js, areas such as the camera setup and foundational 3D shapes, textures and different materials, distinct lighting, and are demonstrated and explained.
  • Element 2 – Environment: Demonstrates environment design using terrain, textures, skyboxes, and scene decoration such as houses and vegetation.
  • Element 3 – Interaction: Demonstrates importing an external player model, keyboard movement, camera following, and collision interaction.
  • Element 4 – Logic: Demonstrates logic within games areas such as different obstacles, collisions, GUI-based health bar and gravitational interactions.
  • Element 5 – Player Control: Shows areas such as differnt gamelay states, input handling of users and scene switching within highly developed cotrol logic.
